# 替换已有 PPTX 的一页

需要保留已有 PPTX 非目标页时必须全文读取本附录，并全文读取[审阅与交付](../review.md)。本操作要求基准 PPTX、完整源项目与明确的目标页映射。

源文件创作使用[页面工作对象](cli.md)。本流程用于二进制整合：将目标页
移植进已有 PPTX，并保留其他页。它不插入、删除或重排交付文件的页面。

## 输入

需要基准 PPTX、对应的完整源项目和目标页在清单中的编号（从 1 开始）。写入前
明确对应关系。单独的 PPTX 不包含可直接恢复的 YAML；重建是另一个任务，不保证
对任意 PPTX 无损反向转换。

## 操作步骤

1. 保留基准文件。用 `page open PROJECT --page N` 打开目标页，通过返回的 work
   修改。非目标源文件和共享素材保持不变；单页图片修改使用该页独立素材。
2. 按[页面与整稿检查](../review.md)查看实际预览和前后衔接，不手工
   改清单来获取预览。
3. 整合到新的输出文件：

```bash
ansatz-slide replace-page --baseline ./baseline.pptx --project ./edited-deck \
  --page 2 -o ./updated.pptx --offline --transition none
```

4. 查看保护报告和确切合并后的 PPTX，分别记录源文件保护、文件包保护和视觉检查。
   源页面预览不能证明合并文件效果正确。

命令先导出完整候选，再移植目标页及其依赖；核对非目标页身份、关系、规范化 XML
语义和递归引用资源，不要求整个 ZIP 字节一致。须使用完整项目和原页码，不能用
单页预览项目替代。

失败时保留基准并修复原因，不全量覆盖。`--force` 只允许替换获准的已有输出，
不允许覆盖基准或无关源文件。拆页、合页和重排使用源分页操作后导出新的完整报告。

## 检查范围

局部修改解决具体可见或解释问题，保留正确内容并检查前后连接。共享主题、字体、
素材或前提变化可能需要扩大审阅。交付遵循[审阅与交付](../review.md#交付)。
