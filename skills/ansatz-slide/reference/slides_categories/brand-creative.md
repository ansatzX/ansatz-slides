# Brand and creative showcase

## Methodology

Identify the subject, audience and creative proposition before selecting visual treatments. Use supplied identity/materials or verified sources within agreed scope. Do not override a user's brand guide because a different style seems more fashionable.

Separate creative concepts from campaign evidence. Outcomes need period, platform/sample and measurement basis. Generated concept art must not impersonate a real product screenshot, customer case or documentary image.

## Visual defaults

Let the subject motivate typography, image choice, palette and composition. Strong contrast, large images, collage or asymmetry can be useful when readable and appropriate; extreme styling is not mandatory. Repeated layouts are allowed when they aid comparison.

Use one coherent visual language, with varied page types only where the content warrants it. Source or create complex artwork externally and retain native explanatory text. Preserve object recognition and factual labels when cropping.

## Acceptance

Is the subject recognizable, the proposition clear, the visual system coherent and the evidence truthful? Does expressive styling support the message rather than conceal it? Do not use visual novelty as a substitute for legibility.
