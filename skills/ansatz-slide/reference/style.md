# 学术幻灯片排版规范

这是当前唯一维护的视觉风格，适用于学术报告、课堂讲解和组会。新建演示文稿
默认使用本规范；字体与颜色均为默认推荐，不是硬性白名单。用户明确要求更换，
或同意 Agent 提出的替换方案后，直接采用，无需重复确认或另建模板。Agent 自行
提出的替换在用户同意前不执行。它只规定外观，不决定报告的
结论、叙事顺序、页数或必做实验。

主要参考为张文杰《2025 帅组组会报告不完全指南》，原文件
`group_report_zhangwenjie_20250911_release.pptx` 共 30 页，采用 16:9 画布、
微软雅黑、白色正文页、彩色顶部标题条和简单图文排列。第 14–18、20–24 页展示
强调、分区、配色、比较和标注方法。原稿是设计参考，不是运行依赖，也不能证明
当前生成结果已经通过验收。不要把原稿的作者、组名、标识、个人图标和科学案例
自动带入新报告。

内容组织统一遵循[学术汇报基本方法](content.md)。每次报告自己的
文字、图片、公式和来源保存在页面文件中，style 不提供这些事实。

## 画布与位置

默认使用 960 × 540（16:9）。下列坐标是当前实现的实用起点，不是对参考稿
每一页的逐项测量。更换画布时按比例调整。

| 区域 | 默认位置 |
| --- | --- |
| 顶部标题条 | 全宽，y=0–48；红色、酒红或紫色背景 |
| 页标题 | x=28、y=4、宽度最多 904、高度 40；白字或与紫底搭配的黄字，左对齐 |
| 正文区域 | x=36–924、y=64–502；与标题保持间距 |
| 页码 | 右下角，y=516–534；小号灰色文字 |
| 当页参考文献 | 为本页使用的材料预留可读区域，位置随布局；具体格式见 content.md |

各页顶部采用“章节: 页标题”：前半部分定位 section，后半部分概括该页主题。
例如 `Background: 低阈值材料设计`、`Methods: 三维分子表征`、`Results: M2 的 ASE 阈值`。
章节名可统一用中文或英文，整稿保持一致；标题简洁凝练，不将多个完整主谓宾分句
用逗号串成流水账。核心发现及其条件写入正文或总结句，标题不必装下整页论证。
保持一行与左右安全边距；过长先精简页标题，将细节移入正文，不省掉章节定位或
大幅缩字。普通内容页保持标题基线和边距稳定。正文局部小标题按讲解需要设置。

封面、章节页可使用纯红／酒红背景与白色大字，也可使用浅底与一个大的章节名。
只放本次报告的真实信息，不强制照片、封面插画或装饰图形。

## 字体与层级

未指定字体时，默认推荐以下四种：

| 字体 | 用途 |
| --- | --- |
| 微软雅黑（Microsoft YaHei） | 默认中文标题与正文 |
| 黑体（SimHei） | 中文标题与正文的备选 |
| Arial | 默认英文与数字 |
| Times New Roman | 英文衬线字体，需要传统学术排版时使用 |

中英混排默认显式设置 `fontFamily: {latin: Arial, ea: Microsoft YaHei}`。
中文可改为黑体，英文可改为 Times New Roman；保持同类文字的字体一致。
其他字体不作为默认推荐；用户指定或同意使用时可以直接替换。
制作时显式写入字体，不依赖导出器省略字段时的底层回退值。
目标环境缺少所选字体时说明缺失，不默默换用推荐范围外的字体。

格式允许分别设置 Latin 和 East Asian 字体，混排时两者都要检查。导出器不嵌入
字体；`customFonts` 只保留元数据，不下载或嵌入字体。字体替换可能改变换行或
导致缺字，须检查实际交付软件中的显示。

| 用途 | 960 × 540 画布上的起始字号 |
| --- | --- |
| 封面标题 | 48–80 pt |
| 章节标题 | 40–48 pt |
| 顶部条内标题 | 24–28 pt |
| 正文主标题 | 28–36 pt |
| 局部小标题 | 24–28 pt，加粗，并明显大于相邻正文 |
| 正文 | 20–24 pt |
| 图注与次要说明 | 16–20 pt |
| 来源与页码 | 10–12 pt；需要听众阅读时适当放大 |

这些是起始值，不是最低字号。正文较多时先调整布局、分配图文空间和整理换行；
仍放不下时可小幅减小正文，比如从 22 pt 调到 20 pt、再到 18 pt，并检查实际阅读效果。
保持同级文字协调，避免连续缩字直到塞满。仍然拥挤或难读时再拆页，不擅自删除内容。
小标题同时通过字号和加粗建立层级，不能只与正文同字号加粗。
使用外部材料的页面须呈现具体参考文献，按[引用规则](content.md#参考文献与外部补充)
执行；位置可就近或在当页文献区，不加空泛 Source 标签。详细来源同时保存在源项目中。
用字号和加粗建立层级，不装饰每个词。数学表达式按[公式说明](production/equations.md)
正式排版；代码采用上述字体并保持内容可读，不用普通文字代替数学排版。科学图里的标签也应在投影距离
下可读。

## 颜色

| 用途 | 默认颜色 |
| --- | --- |
| 正文背景 | 白色 `#FFFFFF` |
| 正文／次要文字 | 近黑 `#202020`、灰 `#666666` |
| 主强调色／顶部标题条 | 红 `#BD2333`、紫 `#780373` |
| 同类结构强调 | 酒红 `#931A2B`、深酒红 `#3A0C11` |
| 局部高亮／对比 | 琥珀黄 `#FFC000`；亮黄 `#FFFF00` 可用于紫底标题 |
| 内容强调与分类 | 红 `#FF0000`、蓝 `#2C68B0`、绿 `#2E8B57` |
| 浅色比较区域 | 浅灰或主强调色的浅色变体 |

红／酒红配色来自组会指南；紫底黄字及红、蓝、绿强调吸收自
`2026_06_26_cunxi_gong.pptx`。它们属于同一风格中的可用配色，不另建模板。
整稿保持顶部条配色一致，正文可用多种强调色区分对象、步骤、问题和结果。
同一颜色尽量保持同一含义，结合文字、箭头和框线说明关系；亮黄适合深紫底，
不用于白底小字。颜色的数量服从表达需要，不限制每页只能一个强调色。

保留科学图原有的数据颜色、刻度和图例，不为统一配色而改动证据。用户或机构
的明确配色可以直接替换标题、背景、正文和强调色，无需另建模板。更换后检查
对比度、可读性与图例对应关系，保留科学图的数据含义。

## 布局选择

外层骨架保持一致，正文按材料安排，不要求固定数量的面板、图或文字块。

- 一张大图，旁边或下方配简短说明。
- 一侧文字、一侧图片，左右与比例均可调整。
- 可比较的图按行或列对齐，并标明比较对象。
- 公式上方或下方配解释与示意图；推导可跨连续页面展开。
- 文字、表格或图片需要空间时占满正文宽度。

三组并列内容须有清楚的分组和较大粗体小标题，可用紧凑浅底区域、分隔线、表格
或其他合适排列，不固定套三个等宽大框。只有少量文字时，不将卡片拉高撑满正文区。
框的尺寸服从实际内容；三个关键词不能仅靠三个巨大空框占据整页。

概览页先确定要展示的关系：技术路线可用流程示意，证据层级可对应分子、薄膜与
器件，结果可配代表图及关键数值。可以用有依据的示意图或重排现有材料提高信息
组织与可调整空间；图须帮助讲解，避免填空装饰。若该页独立信息不足，可紧凑排版
或与相邻内容合并。留白合理，但大片空框与少量孤立文字不是有效的概览结构。

相关对象沿共同边界对齐。主要区域之间可先留约 20–28 个坐标单位，组内采用
更小且一致的间距。允许留白。等分、矩形和圆角面板可以用于真正并列的内容，
不为填空加框。细分割线可帮助分区，图注和符号定义应靠近对应对象，不必全挤
到固定页脚。

## 图片与强调

保持图片比例，完整科学图和表格使用 `fit: {mode: contain}`。整图太小时放大
重要面板或增加标明来源区域的局部图，保留必要坐标、单位和图例。照片、截图
和插画按内容需要选用。

可组合使用加粗、局部彩色文字、箭头、彩色框线、浅色面板、分隔线和短下划线，
突出关键词、对应关系和流程方向。强调应有层级，避免每个对象同样醒目。逐步讲解可用连续页面保持底图位置不变，再逐步增加内容。
局部蒙版可以弱化已解释区域，但应保留无遮罩版本。学术报告默认无元素动画、
无切页动画。

排版参数的可执行示例见[制作与修改](production.md#最小示例)。字段支持范围见
[技术参考](technical.md)，实际页面验收统一见[审阅与交付](review.md)。
