# Worked academic page decisions

Use these contrasts while designing the difficult pages of a report. They are
illustrative briefs, not supplied experimental evidence or a fixed style system.
The rejection reasons matter more than copying the proposed composition.

## Physical model: tree tensor networks

**Weak page:** two equal text panels list “TTNS/TTNO” and “why useful,” define
several acronyms and state that a tree represents the environment. It fits on
the canvas but never shows which parts represent the spin and the bath.

**Correction:** use a source-supported tree schematic as the main explanation.
Identify the spin leaf, representative bath-mode leaves and internal tensors;
mark an internal connection when explaining bond dimension. Place definitions
beside their objects. Explain TTNO separately if operator representation is a
different step in this talk. Label a conceptual schematic as such rather than
claiming it is the actual computational topology.

**Audience check:** can a listener identify where the system and environment
appear and distinguish a physical mode from an internal tensor? “Both panels
have headings” does not answer this question.

## Result: a maximum in an entropy map

**Weak page:** the full multipanel figure is small on one side, while the other
side repeats its caption and asserts that a new phase has been discovered.

**Correction:** when supplied data support an interior maximum, focus on the
relevant map or cross-section and mark that feature without obscuring data.
Retain parameter ranges, time averaging and the color scale. Explain precisely
what differs from the existing classification. A maximum in a finite-time
observable does not by itself establish a phase transition. If other panels
answer different questions, move them to another page or backup, retaining
enough context for the selected panel to be understood.

**Audience check:** can the listener locate the maximum, name the compared
quantity and explain the limitation? An arrow labeled “key finding” without
that information does not fix the page.

## Definition: entropy and mutual information

**Weak page:** several source equations, raw `rho_spin` strings and explanatory
paragraphs are copied into one page headed “correlations.”

**Correction:** select the distinction the audience needs. For example, under a
pure total state, reduced-spin entropy describes spin–full-bath entanglement;
spin–one-mode mutual information measures a different bipartite total
correlation. Show the two partitions with labeled objects and only the equations
needed to distinguish them. Define the reduced states and the purity condition.
Do not depict per-mode mutual informations as additive contributions to total
entanglement without a valid derivation. Put the remaining RDM construction in
backup when it is not the subject of the talk.

**Audience check:** can the listener say which subsystems each quantity relates
and why summing mode values is not automatically a decomposition? Legible
formulas alone do not establish that distinction.

## Negative result: unexplained late-time drift

**Weak page:** call a run successful because it finished, fill a progress page
with implementation work, then list “more simulations” as the next step.

**Correction:** show the observed drift with the relevant conditions and state
what conclusion it prevents. Separate candidate numerical and physical
explanations. Propose a feasible comparison that can discriminate between them,
such as changing a numerical control while holding physical parameters fixed.
Specify what outcomes would inform the diagnosis; do not claim that an unrun
test has proved convergence. If only a table or verbal observation is supplied,
do not manufacture a time-series curve.

**Audience check:** can the group identify the unresolved issue, the evidence
already available and the decision enabled by the next test? Honest diagnosis
can be a complete report without a positive result.

## Boundary: a local edit

**Request:** repair one equation's typography on page 7, preserving the deck.

**Correct scope:** verify that expression and its rendering, preserve all other
pages and use the page-edit procedure. Do not demand a new report outline or
reorganize the talk because the broader academic workflow could improve it.
